# Tyre Thermal Surface Degradation & Carcass 3D Heatmap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a high-precision Tyre Thermal Degradation Engine and interactive 3D Isometric SVG Heatmap visualizing dual-layer temperatures (Surface vs Carcass) and 3 lateral zones (Inner, Center, Outer) with early pathology warnings (Blistering, Graining, Camber Bias) and inflation pressure recommendations.

**Architecture:** A Python thermodynamics module `backend/tools/tyre_thermal.py` estimates physical temperature profiles using G-G friction dynamics, camber offsets, and tyre wear decay. An API endpoint `GET /api/telemetry/tyre-thermal` serves normalized thermal matrices. The frontend applies the strict 4-file pattern, rendering a bespoke 3D isometric SVG chassis with a see-through carcass cutaway toggle, cross-section profile curves, and kiosk-compliant touch targets.

**Tech Stack:** Python 3.13, FastAPI, Pydantic, Next.js 15, React 19, SVG Isometric Geometry, Tailwind CSS, Lucide React, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-23-v2.1-tyre-thermal-degradation-design.md`

## Global Constraints

- **Language & Runtime:** Python 3.13 backend; TypeScript / Next.js 15 frontend.
- **Iconography Standard:** STRICT BAN ON RAW UNICODE EMOJIS in UI. Crisp vector icons only from `lucide-react` (`Flame`, `ShieldAlert`, `Gauge`, `Activity`, `Layers`, `Zap`, `RotateCcw`, `Info`).
- **Kiosk Ergonomics:** All interactive buttons, wheel selectors (`FL`, `FR`, `RL`, `RR`), and cutaway toggle controls must adhere to $\ge 44\text{px} \times 44\text{px}$ touch targets.
- **Frontend Architecture:** Strict 4-file pattern (`types/*.ts` -> `services/*.ts` -> `hooks/*.ts` -> `components/*.tsx`).
- **UI States:** Every component must support all 3 states: Skeleton Loading, Error (with retry trigger), and Empty State.
- **Layout Integrity:** Zero horizontal scroll leaks (`scrollWidth === clientWidth`) across Desktop ($1440\text{px} \times 900\text{px}$), Tablet ($834\text{px} \times 1112\text{px}$), and Mobile ($390\text{px} \times 844\text{px}$).

## Review Focus

1. **Missing Infrared Telemetry Fallback:** When live or historical sessions lack proprietary FOM infrared sensor feeds, `backend/tools/tyre_thermal.py` generates deterministic, physically accurate thermal profiles derived from G-G friction acceleration, camber geometry, and ambient track temps without crashing.
2. **Thermal Zone Gradient Ordering:** For left-hand wheels (`FL`, `RL`), the inner shoulder is physically on the right side of the tyre; for right-hand wheels (`FR`, `RR`), the inner shoulder is on the left side facing the chassis centerline. The visual SVG bands must map correctly according to chassis perspective.
3. **Carcass Cutaway Layer Visibility:** Toggling "Carcass Cutaway" must smoothly reveal the deep core thermal circle without displacing adjacent elements or altering SVG coordinate viewBox geometry.
4. **Inflation Pressure Heuristics:** Center tread temperature exceeding the shoulder average by $>4^\circ\text{C}$ must cleanly trigger `OVER_INFLATED`, while center cooler than shoulders by $>4^\circ\text{C}$ flags `UNDER_INFLATED`.
5. **Multi-Viewport Mobile Ergonomics:** On 390px screens, the 3D isometric canvas and cross-section card must stack vertically without clipped legends or horizontal overflow.

        assert "outer_c" in wheel["surface_temp"]
        assert "carcass_temp_c" in wheel
        assert "pressure_psi" in wheel
        assert "thermal_status" in wheel

def test_camber_bias_heats_inner_shoulder():
    result = compute_tyre_thermal_profile(
        year=2024,
        event="Italian Grand Prix",
        session="Race",
        driver="LEC",
        lap_number=15,
    )
    fl = result["wheels"]["FL"]
    # Front-Left has negative camber; inner shoulder should be warmer than outer
    assert fl["surface_temp"]["inner_c"] > fl["surface_temp"]["outer_c"]
    assert fl["camber_bias_c"] > 0

def test_blistering_detection_on_hot_carcass():

        year=2024,
        event="Italian Grand Prix",
        session="Race",
        driver="LEC",
        lap_number=50, # High lap count with heavy thermal soak
    )

        wheel = result["wheels"][pos]
        assert isinstance(wheel["blistering_risk"], bool)
        assert isinstance(wheel["graining_risk"], bool)
        assert isinstance(wheel["thermal_cliff_risk"], bool)
