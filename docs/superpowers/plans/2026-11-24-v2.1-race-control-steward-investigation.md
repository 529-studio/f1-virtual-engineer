# AI Race Control & Steward Investigation Engine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an authentic, FIA-grade AI Race Control & Steward Investigation Engine that ingests FastF1 race control messages, detects telemetry-based on-track incidents, and runs AI Steward deliberations with vectorized FIA Sporting Regulations RAG to generate defense/prosecution arguments and penalty probability distributions.

**Architecture:** A Python helper `backend/tools/race_control_helper.py` ingests official FastF1 race control messages and extracts incident events, backed by a curated Singapore 2023 fixture and vector search on the FIA Sporting Regulations. A dedicated FastAPI router `backend/app/routers/race_control.py` serves `/api/race-control/feed` and `/api/race-control/investigate`. The frontend follows the strict 4-file pattern, rendering an interactive incident timeline, a side-by-side Steward Investigation Card with SVG penalty probability gauges and verbatim FIA regulation citations, adhering to kiosk touch targets and zero unicode emojis.

**Tech Stack:** Python 3.13, FastAPI, Pydantic, FastF1, Next.js 15, React 19, Tailwind CSS, Lucide React, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-24-v2.1-race-control-steward-investigation-design.md`

## Global Constraints

- **Language & Runtime:** Python 3.13 backend; TypeScript / Next.js 15 frontend.
- **Iconography Standard:** STRICT BAN ON RAW UNICODE EMOJIS in UI. Crisp vector icons only from `lucide-react` (`Scale`, `ShieldAlert`, `FileText`, `CheckCircle2`, `AlertCircle`, `Gavel`, `Clock`, `Flag`).
- **Kiosk Ergonomics:** All interactive buttons, timeline nodes, and incident selector cards must adhere to $\ge 44\text{px} \times 44\text{px}$ touch targets.
- **Frontend Architecture:** Strict 4-file pattern (`types/*.ts` -> `services/*.ts` -> `hooks/*.ts` -> `components/*.tsx`).
- **UI States:** Every component must support all 3 states: Skeleton Loading, Error (with retry trigger), and Empty State.
- **Layout Integrity:** Zero horizontal scroll leaks (`scrollWidth === clientWidth`) across Desktop ($1440\text{px} \times 900\text{px}$), Tablet ($834\text{px} \times 1112\text{px}$), and Mobile ($390\text{px} \times 844\text{px}$).

## Review Focus

1. **Missing FastF1 Messages Fallback:** When a session lacks official text messages in FastF1, `race_control_helper.py` gracefully extracts telemetry-based anomaly events (spikes in lateral/longitudinal deceleration, track limits lap invalidation) without 500 errors.
2. **Offline Fixture Reliability:** For showcase Singapore 2023, the backend pre-bundles `backend/data/fixtures/race_control_singapore_2023.json` to guarantee instant responses during testing and CI/CD without network latency.
3. **FIA RAG Grounding:** Stewards' citations must strictly ground their arguments on indexed FIA Sporting Regulations articles (e.g. Article 33.3, Article 33.4, Article 55) and never hallucinate fictional rule clauses.
4. **Penalty Probability Normalization:** The penalty likelihood breakdown must be non-negative and sum to $100\%$ across `NO_FURTHER_ACTION`, `REPRIMAND`, `TIME_PENALTY_5S`, `TIME_PENALTY_10S`, `DRIVE_THROUGH`, `GRID_DROP`.
5. **Multi-Viewport Mobile Ergonomics:** On 390px screens, the incident timeline and deliberation card must stack vertically without horizontal overflow or clipped text.
