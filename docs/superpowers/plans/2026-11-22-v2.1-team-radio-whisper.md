# AI Team Radio Cockpit & Whisper Transcription Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a production-grade AI Team Radio Cockpit featuring real Singapore 2023 MP3 broadcast streams, Web Audio API 60fps waveform spectrum visualization, Pit-Wall Bandpass filter simulation ($300\,\text{Hz} - 3.4\,\text{kHz}$), tactical NLP classification with an urgency gauge ($1-5$), and offline fixture resilience.

**Architecture:** A FastAPI service and router `/api/radio` ingests and normalizes OpenF1 radio recordings with Redis L2 caching and offline JSON fallback. The frontend implements the strict 4-file pattern: TypeScript DTOs, API service, a Web Audio hook managing dynamic frequency nodes and Biquad filters, and modular UI components styled with Tailwind CSS and Lucide React icons.

**Tech Stack:** Python 3.13, FastAPI, Pydantic, Redis, Next.js 15, React 19, Web Audio API, HTML5 Canvas, Tailwind CSS, Lucide React, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-22-v2.1-team-radio-whisper-design.md`

## Global Constraints

- **Language & Runtime:** Python 3.13 backend; TypeScript / Next.js 15 frontend.
- **Iconography Standard:** STRICT BAN ON RAW UNICODE EMOJIS in UI. Crisp scalable vector icons only from `lucide-react` (`Radio`, `Play`, `Pause`, `Volume2`, `VolumeX`, `Sliders`, `Sparkles`, `AlertTriangle`, `Gauge`, `Clock`, `Activity`).
- **Kiosk Ergonomics:** All interactive buttons, sliders, scrubbers, and filter tabs must have a minimum touch target bounding box of $44\text{px} \times 44\text{px}$.
- **Frontend Architecture:** Strict 4-file pattern (`types/*.ts` -> `services/*.ts` -> `hooks/*.ts` -> `components/*.tsx`).
- **UI States:** Every component must render all 3 states: Skeleton Loading, Error (with retry trigger), and Empty State.
- **Layout Integrity:** Zero horizontal scroll leaks (`scrollWidth === clientWidth`) across Desktop ($1440\text{px} \times 900\text{px}$), Tablet ($834\text{px} \times 1112\text{px}$), and Mobile ($390\text{px} \times 844\text{px}$).

## Review Focus

1. **Upstream Network Drop / Rate Limit:** If OpenF1 returns 429 or times out, `backend/tools/radio_helper.py` seamlessly returns `backend/data/fixtures/team_radio_singapore_2023.json` with status `"fixture_fallback"`.
2. **Audio Streaming Failure / CORS:** If an external Formula 1 MP3 fails to load (CORS policy or offline CI environment), `useTeamRadio` catches the media error and activates an internal Web Audio oscillator synthesizing authentic radio static and beeps without crashing the UI.
3. **Browser Autoplay Policy:** `AudioContext` is suspended by modern browsers until the user explicitly clicks the Play button; the player resumes the context safely on click.
4. **Driver Filter Empty State:** Selecting a driver with 0 radio messages (or unmatched search) displays an interactive Empty State with a "Reset Filter" button.
5. **Mobile Viewport Ergonomics:** On 390px screens, the player collapses from a 2-column split to a vertical stack with responsive touch sliders and full accessibility labels.

    const box = await playBtn.boundingBox();
    expect(box?.width).toBeGreaterThanOrEqual(44);
    expect(box?.height).toBeGreaterThanOrEqual(44);

    // Click play
    await playBtn.click();
    
    // Toggle Pit-Wall Filter
    const filterBtn = page.getByRole("button", { name: /pit-wall|filter/i }).first();
    if (await filterBtn.isVisible()) {
