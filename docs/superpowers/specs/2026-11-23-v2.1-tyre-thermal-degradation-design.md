## 1. Executive Summary & Goals

### Problem
In Formula 1 racing, tyre management determines podium outcomes. Standard telemetry dashboards usually present macro stint degradation as a flat percentage or lap-time penalty (e.g. $+0.12\text{s/lap}$), but completely obscure the underlying thermodynamic mechanics:
1. Difference between **Instantaneous Surface Friction Temperature** ($T_{\text{surf}}$) vs **Deep Carcass Core Temperature** ($T_{\text{carcass}}$).
2. Lateral thermal gradient across the tyre tread: **Inner Shoulder**, **Center Tread**, and **Outer Shoulder**.
3. Physical failure modes: **Graining** (surface rubber tearing when pushed while cold $<85^\circ\text{C}$), **Blistering** (internal carcass overheating $>125^\circ\text{C}$ creating subsurface gas pockets), and **Camber Heat Bias** (excessive negative camber cooking the inside edge).

### Goal
Deliver a premier, scientifically grounded **3D Isometric Tyre Thermal Degradation Engine & Heatmap**:
1. **Dual-Layer 3-Zone Thermodynamic Model**: Computes Surface and Carcass temperatures across 3 lateral zones (Inner, Center, Outer) for all 4 wheels (`FL`, `FR`, `RL`, `RR`).
2. **Interactive Isometric 3D SVG Canvas**: Visualizes the F1 car chassis with 4 wheels in true isometric perspective, featuring false-color thermal camera palettes and an interactive "Carcass Cutaway / See-Through" toggle.
3. **Cross-Section Temperature & Pressure Profiler**: Shows lateral temperature distribution curve against Pirelli compound optimal operating windows ($[95^\circ\text{C}, 110^\circ\text{C}]$) and provides tyre inflation pressure recommendations (`OPTIMAL`, `OVER_INFLATED`, `UNDER_INFLATED`).
4. **Early Warning Pathology Telemetry Badges**: Real-time detection of Graining Risk, Blistering Risk, Thermal Cliff, and Camber Overheat using crisp vector icons.
5. **First-Principles Fallback**: Uses G-G acceleration telemetry, ambient/track temperatures, and stint wear rates to guarantee 100% reliable calculations even when proprietary FOM infrared feeds are unavailable.

## 2. Thermodynamic Physics Formulation

### 2.1 Dual-Layer Energy Balance
For each wheel $w \in \{\text{FL}, \text{FR}, \text{RL}, \text{RR}\}$:
- **Surface Layer Temperature ($T_{\text{surf}}$)**:
  $$T_{\text{surf}} = T_{\text{track}} + \Delta T_{\text{friction}}(\mu, G_{\text{lat}}, G_{\text{lon}}) - \dot{Q}_{\text{convection}}(v_{\text{car}})$$
  Surface responds rapidly ($\tau \approx 0.5 - 1.0\text{s}$) to cornering slip angle $\alpha$, wheel lockup, and traction spin.
- **Carcass Core Layer Temperature ($T_{\text{carcass}}$)**:
  $$T_{\text{carcass}} = T_{\text{ambient}} + \Delta T_{\text{hysteresis}}(\text{stint\_laps}, \text{decay}) + \Delta T_{\text{brake\_radiation}}$$
  Carcass responds slowly ($\tau \approx 10 - 15\text{s}$) to repeated carcass deformation and brake drum heat soak ($800 - 1000^\circ\text{C}$).

### 2.2 Lateral Zone Thermal Distribution & Camber Bias
Each wheel is partitioned into 3 lateral zones:
1. **Inner Shoulder ($T_{\text{inner}}$)**:
   $$T_{\text{inner}} = T_{\text{surf\_base}} + |camber| \cdot k_{\text{camber}}$$
   Front negative camber ($-3.5^\circ$ to $-3.8^\circ$) introduces $+8^\circ\text{C}$ to $+12^\circ\text{C}$ positive thermal bias on the inside edge during straight-line running.
2. **Center Tread ($T_{\text{center}}$)**:
   Sensitive to inflation pressure:
   - If $T_{\text{center}} - \frac{T_{\text{inner}} + T_{\text{outer}}}{2} > 4^\circ\text{C} \implies \text{OVER\_INFLATED}$.
   - If $\frac{T_{\text{inner}} + T_{\text{outer}}}{2} - T_{\text{center}} > 4^\circ\text{C} \implies \text{UNDER\_INFLATED}$.
3. **Outer Shoulder ($T_{\text{outer}}$)**:
   Loaded dynamically in high-speed corners. When cornering right, the Front-Left wheel bears up to 75-80% of lateral load, driving $T_{\text{outer}}$ upwards.

### 2.3 Pathology Detection Matrix
- **Graining Risk**: $T_{\text{surface}} < 85^\circ\text{C}$ and lateral demand $G_{\text{lat}} > 2.2g$.
- **Blistering Risk**: $T_{\text{carcass}} > 125^\circ\text{C}$ and $T_{\text{carcass}} - T_{\text{surface}} \ge 12^\circ\text{C}$.
- **Thermal Cliff**: $T_{\text{bulk}} > 125^\circ\text{C}$ for Soft or $T_{\text{bulk}} > 130^\circ\text{C}$ for Medium/Hard.
- **Camber Overheat**: $T_{\text{inner}} - T_{\text{outer}} > 18^\circ\text{C}$.

## 3. Data Models & API Schemas

### 3.1 Backend Pydantic Schemas (`backend/app/schemas/tyre_thermal.py`)

```python
from typing import Literal
from pydantic import BaseModel, Field

WheelPosition = Literal["FL", "FR", "RL", "RR"]
ThermalStatus = Literal["COLD", "OPTIMAL", "WARM", "OVERHEATING", "BLISTERING"]
PressureStatus = Literal["OPTIMAL", "OVER_INFLATED", "UNDER_INFLATED"]

class TyreZoneTemps(BaseModel):
    inner_c: float = Field(..., description="Inner shoulder temp in °C (camber sensitive)")
    center_c: float = Field(..., description="Center tread temp in °C (pressure sensitive)")
    outer_c: float = Field(..., description="Outer shoulder temp in °C (cornering slip sensitive)")

class TyreWheelThermalData(BaseModel):
    position: WheelPosition
    compound: str = Field(default="MEDIUM", description="SOFT, MEDIUM, HARD, etc.")
    surface_temp: TyreZoneTemps
    carcass_temp_c: float = Field(..., description="Deep internal core carcass temperature in °C")
    bulk_temp_c: float = Field(..., description="Weighted average wheel temperature in °C")
    thermal_status: ThermalStatus
    pressure_status: PressureStatus
    pressure_psi: float = Field(..., description="Current tyre pressure in PSI")
    camber_deg: float = Field(..., description="Static camber angle in degrees")
    graining_risk: bool = Field(default=False)
    blistering_risk: bool = Field(default=False)
    thermal_cliff_risk: bool = Field(default=False)
    camber_bias_c: float = Field(..., description="Inner minus outer temperature difference in °C")

class TyreThermalResponse(BaseModel):
    status: Literal["success", "fallback", "error"]
    year: int
    event: str
    session: str
    driver: str
    lap_number: int
    stint_laps: int
    wheels: dict[WheelPosition, TyreWheelThermalData]
    critical_alerts: list[str] = Field(default_factory=list)
```

### 3.2 Endpoint Contract
- `GET /api/telemetry/tyre-thermal`
  - Query parameters:
    - `year`: int (e.g. 2024)
    - `event`: str (e.g. "Italian Grand Prix")
    - `session_type`: str (e.g. "Race")
    - `driver`: str (e.g. "LEC")
    - `lap_number`: optional int (defaults to last lap or selected lap)

## 4. Frontend Architecture & Isometric 3D Visualization

### 4.1 Strict 4-File Pattern
1. `frontend/src/types/tyre-thermal.ts`: Complete TypeScript types matching backend DTOs.
2. `frontend/src/services/tyreThermalApi.ts`: API service fetching `/api/telemetry/tyre-thermal`.
3. `frontend/src/hooks/useTyreThermal.ts`: Custom hook managing active wheel selection (`FL`, `FR`, `RL`, `RR`), view mode (`surface` vs `carcass_cutaway`), and auto-fetch on lap/driver update.
4. `frontend/src/components/mission-control/TyreThermalHeatmap.tsx`: Main cockpit container.

### 4.2 Sub-Components
- `IsometricTyreCanvas.tsx`: SVG canvas rendering the F1 chassis and 4 wheels in isometric 3D perspective.
  - 3 lateral thermal bands per wheel colored via false-color gradient:
    - Blue (`#38BDF8`): Cold $<85^\circ\text{C}$
    - Emerald Green (`#10B981`): Optimal $95 - 110^\circ\text{C}$
    - Amber (`#F59E0B`): Warm $110 - 125^\circ\text{C}$
    - Crimson Red (`#EF4444`): Overheat / Blistering $>125^\circ\text{C}$
  - Carcass Cutaway Mode: Semi-transparent tread outer ring exposing the inner carcass core circle.
- `TyreCrossSectionCard.tsx`: SVG graph plotting temperature across the profile with Pirelli optimal operating corridor.
- `TyrePathologyBadges.tsx`: Visual alert tags using crisp vector icons (`Flame`, `ShieldAlert`, `Gauge`, `Activity`).

### 4.3 529 Design Rules
- **STRICT BAN ON RAW UNICODE EMOJIS**: Vector icons exclusively from `lucide-react`.
- **Kiosk Ergonomics**: All interactive wheel selection buttons and toggle switches $\ge 44\text{px} \times 44\text{px}$.
- **3 UI States**: Skeleton loading, structured error banner with retry trigger, and empty state.
- **Zero Horizontal Overflow**: Verified across Desktop ($1440\text{px}$), Tablet ($834\text{px}$), Mobile ($390\text{px}$).
