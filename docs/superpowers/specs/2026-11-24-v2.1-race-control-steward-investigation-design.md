## 1. Executive Summary & Goals

### Problem
Formula 1 fans and race strategists closely monitor on-track incidents (Track Limits, Collisions, Safety Car delta infringements, Impeding, Yellow Flag violations). Currently:
1. Standard TV broadcasts and rudimentary timing apps show delayed, brief text banners (e.g. *"INCIDENT INVOLVING CARS 11 AND 44 NOTED"*) without context or telemetry proof.
2. The FIA Sporting Regulations consist of hundreds of pages of complex legalistic text (e.g. Article 33.3 on Track Limits, Article 33.4 on Erratic Driving, Appendix L Chapter IV). Fans have no transparent insight into how stewards evaluate telemetry evidence or decide penalties.
3. The existing `StewardsViewPanel.tsx` in `MissionBoard` is static and superficial, displaying simple hardcoded mock findings without interactive incident timelines, real FastF1 Race Control messages, or probabilistic penalty distributions.

### Goal
Deliver an authentic, FIA-grade **AI Race Control & Steward Investigation Engine**:
1. **FastF1 Race Control Message Ingestion & Incident Parser**:
   Ingests official FIA race control messages from FastF1 (`session.race_control_messages`), parsing lap numbers, driver codes, flags, categories (`TRACK_LIMITS`, `COLLISION`, `SAFETY_CAR`, `INVESTIGATION`, `PENALTY`), and status (`NOTED`, `INVESTIGATING`, `DECISION_REACHED`).
2. **Telemetry Anomaly Fallback**:
   Detects sudden deceleration spikes ($> 4.0g$), spin events ($yaw > 90^\circ$ or steering vs lateral mismatch), and track limits excursions when official race control text feeds are unavailable or sparse.
3. **AI Steward Deliberation & FIA Regulation RAG**:
   Deliberates any selected incident by cross-examining incident telemetry against vectorized FIA Sporting Regulations. Generates:
   - Team Defense Argument (how the driver's race engineer and lawyer defend the action).
   - Steward Prosecution Argument (the regulatory basis for an infringement).
   - Verbatim Article Citation (e.g. *Article 33.3 of the 2023 FIA Formula One Sporting Regulations*).
   - Probabilistic Penalty Matrix ($5\text{s}, 10\text{s}$, Reprimand, Warning, No Further Action).
4. **Interactive Race Control Cockpit UI**:
   - Scrollable Incident Timeline with lap markers and status pills.
   - Steward Investigation Card with SVG Penalty Probability Gauge and rule quote card.
   - Kiosk ergonomics ($\ge 44\text{px} \times 44\text{px}$ touch targets), 3 UI states (Skeleton, Error, Empty), and strict zero unicode emojis.
5. **Showcase Grand Prix & Offline Fixture**:
   Singapore Grand Prix 2023 (high drama: Russell lap 62 barrier impact, Ocon gearbox failure / VSC, Sainz strategic DRS tow, Perez/Albon collision investigation) backed by `backend/data/fixtures/race_control_singapore_2023.json` for offline reliability.

## 3. Data Models & API Contracts

### 3.1 Pydantic Schemas (`backend/app/schemas/race_control.py`)

```python
from typing import Literal
from pydantic import BaseModel, Field

IncidentCategory = Literal[
    "COLLISION",
    "TRACK_LIMITS",
    "SAFETY_CAR_INFECT",
    "IMPEDING",
    "YELLOW_FLAG",
    "UNSAFE_RELEASE",
    "TECHNICAL_FLAG",
]

IncidentStatus = Literal[
    "NOTED",
    "UNDER_INVESTIGATION",
    "DECISION_REACHED",
    "NO_FURTHER_ACTION",
]

PenaltyType = Literal[
    "NO_FURTHER_ACTION",
    "REPRIMAND",
    "TIME_PENALTY_5S",
    "TIME_PENALTY_10S",
    "DRIVE_THROUGH",
    "GRID_DROP",
]

class RaceControlMessageItem(BaseModel):
    id: str
    lap: int
    timestamp_str: str
    category: IncidentCategory
    status: IncidentStatus
    drivers_involved: list[str] = Field(default_factory=list)
    flag: str | None = None  # GREEN, YELLOW, DOUBLE_YELLOW, RED, SC, VSC, CHEQUERED
    message: str
    description: str

class RaceControlFeedResponse(BaseModel):
    status: Literal["success", "fallback", "error"]
    year: int
    event: str
    session: str
    total_incidents: int
    items: list[RaceControlMessageItem]

class StewardInvestigationRequest(BaseModel):
    incident_id: str
    year: int = 2023
    event: str = "Singapore Grand Prix"
    session: str = "Race"

class PenaltyProbability(BaseModel):
    penalty: PenaltyType
    probability_pct: int
    description: str

class StewardInvestigationResponse(BaseModel):
    status: Literal["success", "fallback", "error"]
    incident_id: str
    category: IncidentCategory
    drivers_involved: list[str]
    regulation_article: str
    regulation_title: str
    regulation_snippet: str
    team_defense_argument: str
    steward_prosecution_argument: str
    predicted_verdict: PenaltyType
    confidence_pct: int
    penalty_breakdown: list[PenaltyProbability]
```

### 3.2 Endpoints (`backend/app/routers/race_control.py`)
- `GET /api/race-control/feed`:
  - Query params: `year: int`, `event: str`, `session: str`
  - Returns chronological list of race control messages and incidents.
- `POST /api/race-control/investigate`:
  - Accepts `StewardInvestigationRequest`
  - Searches FIA Sporting Regulations Vector DB via `knowledge_retriever.py`
  - Generates structured defense/prosecution arguments and penalty breakdown.

## 4. Frontend Architecture & Ergonomics

### 4.1 Strict 4-File Pattern
1. `frontend/src/types/race-control.ts`: DTOs and incident interfaces.
2. `frontend/src/services/raceControlApi.ts`: API service fetching feed and posting investigation requests.
3. `frontend/src/hooks/useRaceControl.ts`: Hook managing active incident selection, filter by category (`ALL`, `COLLISION`, `TRACK_LIMITS`, `PENALTY`), and async AI deliberation.
4. `frontend/src/components/mission-control/RaceControlPanel.tsx`: Main cockpit container.

### 4.2 Sub-Components
- `RaceControlTimeline.tsx`:
  - Visual horizontal/vertical timeline showing race lap progression.
  - Incident pills with severity indicators:
    - Yellow: `NOTED`
    - Amber/Orange: `UNDER_INVESTIGATION`
    - Crimson Red: `TIME_PENALTY_5S` or `TIME_PENALTY_10S`
    - Green/Gray: `NO_FURTHER_ACTION`
  - Filter pills for categories (`ALL`, `COLLISION`, `TRACK_LIMITS`, `SC/FLAGS`).
- `StewardInvestigationCard.tsx`:
  - Visualizes the FIA Steward deliberation for the active incident.
  - Two-column / split card:
    - Left: Team Defense Argument vs Steward Counter-Argument.
    - Right: Verbatim FIA Regulation Article citation card + SVG Radial/Bar Penalty Probability Distribution.
- `RaceControlBadge.tsx`: Header badge in `StrategyHUD.tsx` notifying active steward investigations.

### 4.3 529 Standards
- **STRICT BAN ON RAW UNICODE EMOJIS**: Scalable vector icons from `lucide-react` exclusively (`Scale`, `ShieldAlert`, `FileText`, `CheckCircle2`, `AlertCircle`, `Gavel`, `Clock`, `Flag`).
- **Kiosk Ergonomics**: All interactive buttons, timeline nodes, and incident cards $\ge 44\text{px} \times 44\text{px}$.
- **3 UI States**: Skeleton loading state, error banner with retry trigger, and clean empty state.
- **Zero Horizontal Overflow**: Verified across Desktop ($1440\text{px}$), Tablet ($834\text{px}$), Mobile ($390\text{px}$).
